## 4. Why the manual seed matters

The downstream consumer is the **shadow GitHub negative-space collector** (Track
D, deferred Phase 0 task `p0.9`). It watches founders' GitHub profiles for the
"public → private" transition that LOB.txt's Method 3 (Negative Space Detection)
described.

Without a bounded watchlist, the negative-space collector would:
- Scan unbounded GitHub users → bust the 5000 req/hr authenticated budget in
  hours
- Have no signal-to-noise floor (most GitHub users are not founders)
- Be uncorrelated with the engine's existing canonical_keys

With a bounded watchlist of 50-500 known founders, it:
- Stays under the 5000 req/hr budget at any reasonable polling cadence
- Surfaces transitions that map to *founders the analyst already cares about*
- Enables the LOB.txt Method 3 differentiator with low operational cost

**This is the highest-leverage deferred Phase 0 collector.** It is unblocked
by hours of human seed work. Track E exists to make sure those hours actually
happen.

## 6. Schema reminders (from `scripts/data/README.md`)

| Column | Required | Description |
|---|---|---|
| `founder_id` | yes | unique stable ID, e.g. `manual_001`, `manual_002` |
| `full_name` | yes | human-readable name |
| `github_username` | yes | GitHub handle (no `@`) |
| `linkedin_url` | no | LinkedIn profile URL if known |
| `associated_company_id` | no | link to a company in `company_files` if known |

The populator script adds two more columns (`source = "manual_seed"`,
`added_at = <utc iso>`) automatically when generating the watchlist output.

## 7. Cap and rate-budget math

| Constraint | Value |
|---|---|
| GitHub authenticated rate limit | 5,000 req/hr |
| Budget for negative-space collector | 40% = 2,000 req/hr |
| API calls per founder per scan | ~3 (user info + recent events + recent commits) |
| Founders per scan | 2,000 / 3 = ~666 |
| Recommended cap | 500 (40% headroom) |
| Watchlist target | 50-500 |

50 is the floor (enough to make the collector worth running). 500 is the
ceiling (enough to fit safely under the rate budget). Anywhere in this range
is fine for Track D.

## 9. Hand-off to Track D (post 2026-04-19)

Once the watchlist exists, Track D's GitHub negative-space collector reads it
at startup, polls each founder's public events, and alerts when:
- A founder goes from N public commits/week to 0 (potential stealth mode)
- A founder's most recent public repo gets archived
- A founder appears as a watcher/star but no contributions

These are LOB.txt Method 3 signals. The collector lives in
`collectors/github_negative_space.py` (NEW file, Move 1+ deliverable, NOT
Move 0).

The collector spec is **out of scope for Track E.** Track E only delivers
the watchlist; the collector is a separate Move 1 deliverable that depends on it.
